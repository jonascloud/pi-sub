# Source terms

This coordinator was implemented around Pi's public RPC interface rather than porting the in-process subagent framework. Its design and calibration methodology were informed by [jonascloud/pi-subagent](https://github.com/jonascloud/pi-subagent), the `pi-subagents` package in [gotgenes/pi-packages](https://github.com/gotgenes/pi-packages), and [tintinweb/pi-subagents](https://github.com/tintinweb/pi-subagents). The upstream MIT notice is retained in [LICENSE](LICENSE).

The historical calibration observations and fixed reference-cost baseline in [the assessment instructions](instructions/model-capabilities.md) originate from Artificial Analysis Intelligence Index v5.0.1 model pages. Power assignments are local judgments, not Artificial Analysis measurements or endorsements. Reference sources include [Luna non-reasoning](https://artificialanalysis.ai/models/gpt-6-luna-non-reasoning), [Luna high](https://artificialanalysis.ai/models/gpt-6-luna-high), [Terra low](https://artificialanalysis.ai/models/gpt-6-1-terra-low), [Terra medium](https://artificialanalysis.ai/models/gpt-6-1-terra-medium), [Terra high](https://artificialanalysis.ai/models/gpt-6-1-terra-high), and [Sol high](https://artificialanalysis.ai/models/gpt-6-1-sol-high). Those observations were acquired on 2026-11-05; exact source and review records remain in the reference project's archived model-catalog evidence.

No operational model catalog is bundled. Generated research evidence is intended for private local use and retains its source terms. The code license does not relicense third-party benchmark observations. Review [Artificial Analysis terms](https://artificialanalysiscdn.com/legal/ProDataPlatformTerms.pdf) and applicable public-page usage terms before redistributing data.
